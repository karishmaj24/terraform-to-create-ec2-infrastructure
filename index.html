How Our CI/CD Pipeline Works

From code commit to live application

01
🔗

GitHub

Developers push application source code to the GitHub repository.

02
🔔

Webhook

GitHub Webhook automatically triggers the Jenkins pipeline after a code push.

03
⚙️

Jenkins

Jenkins checks out the latest source code and starts the automated pipeline.

04
🐳

Docker Build

Jenkins builds a Docker image containing the web application.

05
📦

Docker Hub

The generated Docker image is pushed to Docker Hub for deployment.

06
☁️

AWS EC2

The Docker container runs on AWS EC2 and makes the application available online.

About CloudDeploy

CloudDeploy is a real-world DevOps project designed to demonstrate an automated CI/CD workflow for web applications. The project integrates GitHub, Jenkins, Docker, Docker Hub, Terraform and AWS EC2. GitHub Webhook automatically triggers Jenkins, Jenkins builds the Docker image, and the application is deployed as a Docker container on AWS EC2.
